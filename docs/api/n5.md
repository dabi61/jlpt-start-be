# N5 Practice API + Import Guide

Tài liệu này mô tả API mới cho bộ đề N5 và cách import dữ liệu từ folder `n5/`.

## 1. Kiến trúc dữ liệu

Dataset được tách thành 6 model:
- `N5Section`: nhóm lớn (`Doc`, `Nghe`, `NguPhap`, `TuVung`).
- `N5Subcategory`: nhóm con (vd `NgheHieuChuDe`, `DoanVanNgan`).
- `N5Exam`: mỗi file JSON nguồn.
- `N5Question`: một block câu hỏi trong JSON (`Questions.Questions[]`).
- `N5QuestionItem`: từng phần tử trong `content[]` của một question.
- `N5MediaAsset`: registry media đã upload lên R2 (local + remote fallback).

## 2. API endpoints

Base path: `/api/n5/`

- `sections/`
- `subcategories/`
- `exams/`
- `questions/`
- `question-items/`
- `media-assets/`

Các endpoint đều hỗ trợ CRUD (`GET/POST` list, `GET/PUT/PATCH/DELETE` detail) và có mặt trên Swagger `/api/docs/`.

Custom endpoints:
- `GET /api/n5/exams/{id}/questions/`
- `GET /api/n5/questions/{id}/items/`

## 3. Filter quan trọng

- `subcategories`: `?section=<id>`, `?section_code=<code>`
- `exams`: `?section=<id>`, `?section_code=<code>`, `?subcategory=<id>`, `?subcategory_code=<code>`, `?is_active=true|false`
- `questions`: `?section=<id>`, `?section_code=<code>`, `?subcategory=<id>`, `?subcategory_code=<code>`, `?exam=<id>`, `?kind=...`, `?source_id=...`
- `question-items`: `?question=<id>`, `?exam=<id>`, `?subcategory=<id>`, `?section=<id>`
- `media-assets`: `?media_type=IMAGE|AUDIO|OTHER`, `?source_type=LOCAL|REMOTE`

## 4. Import dữ liệu + upload media R2

### 4.1 Yêu cầu biến môi trường

Backend phải có đủ biến:

```env
R2_ENDPOINT_URL=...
R2_REGION=auto
R2_BUCKET_NAME=startjlpt
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_PUBLIC_BASE_URL=https://storage.jlpt.codes
```

### 4.2 Chạy migration

```bash
python manage.py makemigrations n5
python manage.py migrate
```

### 4.3 Import chính thức (upload local media trước, rồi import JSON)

```bash
python manage.py import_n5_data --source-dir n5 --prefix n5/images
```

Mặc định command sẽ:
1. Upload toàn bộ media local (`png/jpg/jpeg/gif/mp3/wav/m4a/ogg`) trong `n5/` lên R2 prefix `n5/images`.
2. Parse 14 file JSON, tạo Section/Subcategory/Exam/Question/QuestionItem.
3. Map URL media trong JSON sang URL R2.
4. Với URL không map được từ local, command sẽ thử fetch remote URL rồi upload lên R2 (fallback).

### 4.4 Các option hữu ích

- `--clear`: xóa dữ liệu N5 cũ trước khi import.
- `--skip-upload-local`: không upload media local.
- `--skip-upload-remote`: không fetch/upload fallback cho URL remote chưa map được.
- `--dry-run`: chỉ parse/kiểm tra, không ghi DB và không upload.

Ví dụ dry-run:

```bash
python manage.py import_n5_data --source-dir n5 --dry-run
```

## 5. Gợi ý kiểm tra sau import

- `GET /api/n5/exams/?page=1&page_size=20`
- `GET /api/n5/questions/?exam=<exam_id>&page=1&page_size=20`
- `GET /api/n5/media-assets/?media_type=AUDIO&page=1&page_size=20`
