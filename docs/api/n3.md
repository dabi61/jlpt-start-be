# N3 Practice API (JLPT N3 Dataset)

Tài liệu này mô tả:
1. API dữ liệu N3 (CRUD + filter/search/order).
2. Định dạng response envelope của backend.
3. Pipeline import JSON + upload media lên Cloudflare R2.

Base path: `/api/n3/`

## 1. Authentication (bắt buộc)

Tất cả endpoint N3 đều yêu cầu đăng nhập (JWT Bearer).

- Lấy access token: `POST /api/auth/login/` (xem thêm `docs/api/endpoints.md`).
- Gọi API với header:

```bash
Authorization: Bearer <ACCESS_TOKEN>
```

Swagger: vào `/api/docs/` -> `Authorize` -> dán `Bearer <ACCESS_TOKEN>`.

## 2. Response Envelope (quan trọng)

Backend luôn wrap response JSON theo envelope:

```json
{
  "meta": {
    "code": 200,
    "type": "SUCCESS",
    "message": "Request successful."
  },
  "data": {}
}
```

Ví dụ lỗi auth (401):

```json
{
  "meta": {
    "code": 401,
    "type": "ERROR",
    "message": "Missing or invalid authorization header."
  },
  "data": {}
}
```

Lưu ý: OpenAPI schema/Swagger có thể hiển thị **shape “raw” của serializer** (không có envelope),
nhưng runtime response thực tế vẫn được wrap vào `meta` + `data` như trên.

## 3. Pagination + query params chung

Pagination dùng `PageNumberPagination`:

- `page` (mặc định `1`)
- `page_size` (mặc định `20`, tối đa `100`)

Với list endpoint, `data` sẽ có dạng:

```json
{
  "meta": { "code": 200, "type": "SUCCESS", "message": "Request successful." },
  "data": {
    "count": 14,
    "next": "https://jlpt.codes/api/n3/exams/?page=2",
    "previous": null,
    "results": []
  }
}
```

Các query param chung cho hầu hết list endpoints:

- `search=<text>` (DRF SearchFilter)
- `ordering=<field>` hoặc `ordering=-<field>`

## 4. Data model (khái niệm)

Dataset N3 được tách thành 6 model chính:

### 4.1 `N3Section`

Nhóm lớn: `Doc`, `Nghe`, `NguPhap`, `TuVung` (code là slug).

Fields chính:
- `code` (slug, unique)
- `name`
- `description`
- `sort_order`

### 4.2 `N3Subcategory`

Nhóm con theo từng section (vd `DoanVanNgan`, `NgheHieuChuDe`).

Fields chính:
- `section` (FK -> `N3Section`)
- `code` (slug)
- `source_key` (key gốc trong dataset, dạng CamelCase)
- `name`
- `sort_order`
- `metadata` (JSON)

### 4.3 `N3Exam`

Mỗi file JSON nguồn -> 1 exam.

Fields chính:
- `subcategory` (FK -> `N3Subcategory`)
- `slug`, `name`
- `source_file` (đường dẫn tương đối của JSON, ví dụ `Nghe/NgheHieuChuDe/Mytest_N3_16.json`)
- `source_kind` (lấy từ row đầu tiên nếu có)
- `time_limit_seconds`
- `question_count`
- `is_active`
- `metadata` (JSON)

### 4.4 `N3Question`

1 question tương ứng 1 “row” trong `Questions.Questions[]`.

Fields chính:
- `exam` (FK -> `N3Exam`)
- `source_id` (id trong dataset)
- `display_order`
- `kind`, `title`, `jlpt_level`
- `score`, `scores` (JSON), `correct_answers` (JSON), `time_tracking`
- `general_audio_url`, `general_image_url`
- `general_txt_read`, `general_text_read_en`, `general_text_read_vn`
- `source_import`, `raw_general` (JSON, để trace dữ liệu gốc)

### 4.5 `N3QuestionItem`

Mỗi phần tử trong `content[]` của `N3Question`.

Fields chính:
- `question` (FK -> `N3Question`)
- `item_order`
- `question_text`
- `image_url`
- `answers` (JSON array; giữ nguyên cấu trúc dataset)
- `choose_answer` (int, optional)
- `correct_answer` (int, optional)
- `explain_en`, `explain_vn`
- `raw_explain`, `raw_data` (JSON gốc)

Lưu ý quan trọng:
- `choose_answer` nằm trên **record dataset** nên mang tính **global** (mọi user sẽ “đè” nhau).
  Nếu bạn muốn tracking theo từng user, hãy dùng Practice Attempts API: `docs/api/practice.md`.

### 4.6 `N3MediaAsset`

Registry các file media đã upload lên R2 (dùng để debug và cache mapping).

Fields chính:
- `source_type`: `LOCAL` hoặc `REMOTE`
- `media_type`: `IMAGE` | `AUDIO` | `OTHER`
- `source_url` (nếu là remote fallback)
- `source_path`, `source_basename` (nếu là local)
- `r2_key`, `public_url`, `content_type`, `content_length`
- `metadata` (JSON)

## 5. API endpoints (chi tiết)

Tất cả endpoint dưới đây đều hỗ trợ CRUD:

- List: `GET /api/n3/<resource>/`
- Create: `POST /api/n3/<resource>/`
- Detail: `GET /api/n3/<resource>/{id}/`
- Update: `PUT/PATCH /api/n3/<resource>/{id}/`
- Delete: `DELETE /api/n3/<resource>/{id}/`

### 5.1 Sections: `/api/n3/sections/`

Query params:
- `search` (search fields: `code`, `name`, `description`)
- `ordering` (fields: `sort_order`, `name`, `updated_at`)
- `page`, `page_size`

Ví dụ:

```bash
curl -sS \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  "https://jlpt.codes/api/n3/sections/?page=1&page_size=20"
```

### 5.2 Subcategories: `/api/n3/subcategories/`

Filter params:
- `section=<id>`
- `section_code=<slug>`

Search fields: `name`, `code`, `source_key`, `section__name`, `section__code`
Ordering fields: `sort_order`, `name`, `updated_at`

Ví dụ:

```bash
curl -sS \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  "https://jlpt.codes/api/n3/subcategories/?section_code=nghe"
```

### 5.3 Exams: `/api/n3/exams/`

Filter params:
- `section=<id>`
- `section_code=<slug>`
- `subcategory=<id>`
- `subcategory_code=<slug>`
- `is_active=true|false|1|0|yes|no`

Search fields: `name`, `slug`, `source_file`, `source_kind`, `subcategory__name`
Ordering fields: `name`, `question_count`, `time_limit_seconds`, `updated_at`

#### Custom: `GET /api/n3/exams/{id}/questions/`

Trả về danh sách questions thuộc exam đó (paginated).
Response dùng `N3QuestionListSerializer` (không có `items`).

Ví dụ:

```bash
curl -sS \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  "https://jlpt.codes/api/n3/exams/<exam_id>/questions/?page=1&page_size=20"
```

### 5.4 Questions: `/api/n3/questions/`

List serializer:
- `GET /api/n3/questions/` dùng `N3QuestionListSerializer` (nhẹ, không include `items`).

Detail serializer:
- `GET /api/n3/questions/{id}/` dùng `N3QuestionSerializer` (include `items`).

Filter params:
- `section=<id>`
- `section_code=<slug>`
- `subcategory=<id>`
- `subcategory_code=<slug>`
- `exam=<id>`
- `kind=<string>`
- `source_id=<int>`

Search fields: `title`, `kind`, `source_id`, `exam__name`
Ordering fields: `display_order`, `source_id`, `score`, `updated_at`

#### Custom: `GET /api/n3/questions/{id}/items/`

Trả về toàn bộ items của 1 question (không paginate).

Ví dụ:

```bash
curl -sS \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  "https://jlpt.codes/api/n3/questions/<question_id>/items/"
```

### 5.5 Question items: `/api/n3/question-items/`

Filter params:
- `question=<id>`
- `exam=<id>`
- `subcategory=<id>`
- `section=<id>`

Search fields: `question_text`, `question__title`
Ordering fields: `item_order`, `correct_answer`, `updated_at`

Ví dụ (lấy item theo question, có paginate):

```bash
curl -sS \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  "https://jlpt.codes/api/n3/question-items/?question=<question_id>&page=1&page_size=50"
```

Ví dụ lưu đáp án theo user (khuyến nghị, không sửa dataset):

```bash
# 1) Tạo/resume attempt cho exam
curl -sS -X POST \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  -H "Content-Type: application/json" \\
  -d '{\"level\":\"N3\",\"exam_id\":<exam_id>,\"resume\":true}' \\
  "https://jlpt.codes/api/practice/attempts/"

# 2) Lưu đáp án cho 1 question-item
curl -sS -X POST \\
  -H "Authorization: Bearer <ACCESS_TOKEN>" \\
  -H "Content-Type: application/json" \\
  -d '{\"question_item_id\":<item_id>,\"selected_answer\":2}' \\
  "https://jlpt.codes/api/practice/attempts/<attempt_id>/answers/"
```

### 5.6 Media assets: `/api/n3/media-assets/`

Filter params:
- `media_type=IMAGE|AUDIO|OTHER` (không phân biệt hoa thường)
- `source_type=LOCAL|REMOTE` (không phân biệt hoa thường)

Search fields: `source_basename`, `source_path`, `source_url`, `r2_key`, `public_url`
Ordering fields: `created_at`, `updated_at`, `media_type`, `source_type`

## 6. Gợi ý flow cho frontend/client

Flow đề xuất:

1. `GET /api/n3/sections/`
2. `GET /api/n3/subcategories/?section=<section_id>`
3. `GET /api/n3/exams/?subcategory=<subcategory_id>&is_active=true`
4. `GET /api/n3/exams/{exam_id}/questions/?page=1&page_size=20`
5. `GET /api/n3/questions/{question_id}/` (lấy full + `items`)
6. Lưu đáp án theo user: `POST /api/practice/attempts/{attempt_id}/answers/` (xem `docs/api/practice.md`).

## 7. Import JSON + upload media lên Cloudflare R2

### 7.1 Biến môi trường bắt buộc

Thêm vào `.env`:

```env
R2_ENDPOINT_URL=https://<account_id>.r2.cloudflarestorage.com
R2_REGION=auto
R2_BUCKET_NAME=startjlpt
R2_ACCESS_KEY_ID=<access_key_id>
R2_SECRET_ACCESS_KEY=<secret_access_key>
R2_PUBLIC_BASE_URL=https://storage.jlpt.codes
```

### 7.2 Migrate

```bash
python manage.py migrate
```

### 7.3 Import lần đầu (upload local media trước, rồi import JSON)

```bash
python manage.py import_n3_data --source-dir n3 --prefix n3/images --clear
```

Mặc định command sẽ:
- Upload toàn bộ media local (`png/jpg/jpeg/gif/mp3/wav/m4a/ogg`) trong `n3/` lên prefix `n3/images`.
- Import tất cả file JSON trong `n3/` (hiện tại là 17 file) và map URL sang `R2_PUBLIC_BASE_URL`.
- Nếu URL remote không map được từ local: sẽ download URL đó và upload lên `n3/images/remote/...` (fallback).

### 7.4 Resume nhanh (khi media đã upload rồi)

Nếu bạn đã upload media lên R2 từ trước, và chỉ muốn import nốt JSON hoặc tránh chạy lại file đã có:

```bash
python manage.py import_n3_data \\
  --source-dir n3 \\
  --prefix n3/images \\
  --skip-upload-local \\
  --skip-upload-remote \\
  --skip-existing-exams
```

### 7.5 Dry-run

```bash
python manage.py import_n3_data --source-dir n3 --dry-run
```

- `GET /api/n3/media-assets/?media_type=AUDIO&page=1&page_size=20`
