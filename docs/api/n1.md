# N1 Practice API (JLPT N1 Dataset)

Tài liệu này mô tả:
1. API dữ liệu N1 (CRUD + filter/search/order).
2. Định dạng response envelope của backend.
3. Pipeline import JSON + upload media lên Cloudflare R2.

Base path: `/api/n1/`

## 1. Authentication (bắt buộc)

Tất cả endpoint N1 đều yêu cầu đăng nhập (JWT Bearer).

- Lấy access token: `POST /api/auth/login/` (xem thêm `docs/api/endpoints.md`).
- Gọi API với header:

```bash
Authorization: Bearer <ACCESS_TOKEN>
```

Swagger: vào `/api/docs/` -> `Authorize` -> dán `Bearer <ACCESS_TOKEN>`.

## 2. Response Envelope (quan trọng)

Backend luôn wrap response JSON theo envelope:

```json
{
  "meta": {
    "code": 200,
    "type": "SUCCESS",
    "message": "Request successful."
  },
  "data": {}
}
```

Lưu ý: OpenAPI schema/Swagger có thể hiển thị **shape “raw” của serializer** (không có envelope),
nhưng runtime response thực tế vẫn được wrap vào `meta` + `data`.

## 3. Pagination + query params chung

Pagination dùng `PageNumberPagination`:

- `page` (mặc định `1`)
- `page_size` (mặc định `20`, tối đa `100`)

Các query param chung cho hầu hết list endpoints:

- `search=<text>` (DRF SearchFilter)
- `ordering=<field>` hoặc `ordering=-<field>`

## 4. Data model (khái niệm)

Dataset N1 được tách thành 6 model chính:

- `N1Section`: nhóm lớn `Doc`, `Nghe`, `NguPhap`, `TuVung`.
- `N1Subcategory`: nhóm con (vd `DoanVanDai`, `DocHieuTongHop`, `NgheHieuTongHop`...).
- `N1Exam`: mỗi file JSON nguồn -> 1 exam.
- `N1Question`: 1 row trong `Questions.Questions[]`.
- `N1QuestionItem`: 1 phần tử trong `content[]` của question.
- `N1MediaAsset`: registry media đã upload lên R2.

Lưu ý quan trọng:
- `choose_answer` trên `QuestionItem` là field của **dataset** nên mang tính **global**.
  Nếu muốn tracking theo từng user, dùng Practice Attempts API: `docs/api/practice.md`.

## 5. API endpoints (chi tiết)

Tất cả endpoint dưới đây đều hỗ trợ CRUD:

- List: `GET /api/n1/<resource>/`
- Create: `POST /api/n1/<resource>/`
- Detail: `GET /api/n1/<resource>/{id}/`
- Update: `PUT/PATCH /api/n1/<resource>/{id}/`
- Delete: `DELETE /api/n1/<resource>/{id}/`

### 5.1 Sections: `/api/n1/sections/`

Query params:
- `search` (fields: `code`, `name`, `description`)
- `ordering` (fields: `sort_order`, `name`, `updated_at`)
- `page`, `page_size`

### 5.2 Subcategories: `/api/n1/subcategories/`

Filter params:
- `section=<id>`
- `section_code=<slug>`

### 5.3 Exams: `/api/n1/exams/`

Filter params:
- `section=<id>`
- `section_code=<slug>`
- `subcategory=<id>`
- `subcategory_code=<slug>`
- `is_active=true|false|1|0|yes|no`

#### Custom: `GET /api/n1/exams/{id}/questions/`

Trả về danh sách `N1Question` thuộc exam đó (có pagination).

### 5.4 Questions: `/api/n1/questions/`

Filter params:
- `section=<id>` / `section_code=<slug>`
- `subcategory=<id>` / `subcategory_code=<slug>`
- `exam=<id>`
- `kind=<text>`
- `source_id=<int>`

#### Custom: `GET /api/n1/questions/{id}/items/`

Trả về danh sách `N1QuestionItem` của question (không pagination).

### 5.5 Question Items: `/api/n1/question-items/`

Filter params:
- `question=<id>`
- `exam=<id>`
- `subcategory=<id>`
- `section=<id>`

### 5.6 Media Assets: `/api/n1/media-assets/`

Filter params:
- `media_type=IMAGE|AUDIO|OTHER`
- `source_type=LOCAL|REMOTE`

## 6. Import JSON + upload media lên R2

### 6.1 Chạy import (local)

Upload local media lên R2 và import vào DB:

```bash
PYTHONUNBUFFERED=1 \\
python manage.py import_n1_data --source-dir n1 --prefix n1/images --clear
```

Re-import nhanh (media đã upload rồi):

```bash
PYTHONUNBUFFERED=1 \\
python manage.py import_n1_data --source-dir n1 --prefix n1/images --skip-upload-local
```

## 7. Tracking tiến độ theo user (Option 2)

Để lưu câu trả lời theo từng user và chấm điểm:

- Xem `docs/api/practice.md`
- Flow:
  1. `POST /api/practice/attempts/` (level=`N1`, exam_id)
  2. `GET /api/n1/exams/{exam_id}/questions/`
  3. `POST /api/practice/attempts/{attempt_id}/answers/`
  4. `POST /api/practice/attempts/{attempt_id}/submit/`
