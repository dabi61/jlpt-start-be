# N2 Practice API (JLPT N2 Dataset)

Tài liệu này mô tả:
1. API dữ liệu N2 (CRUD + filter/search/order).
2. Định dạng response envelope của backend.
3. Pipeline import JSON + upload media lên Cloudflare R2.

Base path: `/api/n2/`

## 1. Authentication (bắt buộc)

Tất cả endpoint N2 đều yêu cầu đăng nhập (JWT Bearer).

- Lấy access token: `POST /api/auth/login/` (xem thêm `docs/api/endpoints.md`).
- Gọi API với header:

```bash
Authorization: Bearer <ACCESS_TOKEN>
```

Swagger: vào `/api/docs/` -> `Authorize` -> dán `Bearer <ACCESS_TOKEN>`.

## 2. Response Envelope (quan trọng)

Backend luôn wrap response JSON theo envelope:

```json
{
  "meta": {
    "code": 200,
    "type": "SUCCESS",
    "message": "Request successful."
  },
  "data": {}
}
```

Ví dụ lỗi auth (401):

```json
{
  "meta": {
    "code": 401,
    "type": "ERROR",
    "message": "Missing or invalid authorization header."
  },
  "data": {}
}
```

Lưu ý: OpenAPI schema/Swagger có thể hiển thị **shape “raw” của serializer** (không có envelope),
nhưng runtime response thực tế vẫn được wrap vào `meta` + `data` như trên.

## 3. Pagination + query params chung

Pagination dùng `PageNumberPagination`:

- `page` (mặc định `1`)
- `page_size` (mặc định `20`, tối đa `100`)

Với list endpoint, `data` sẽ có dạng:

```json
{
  "meta": { "code": 200, "type": "SUCCESS", "message": "Request successful." },
  "data": {
    "count": 14,
    "next": "https://jlpt.codes/api/n2/exams/?page=2",
    "previous": null,
    "results": []
  }
}
```

Các query param chung cho hầu hết list endpoints:

- `search=<text>` (DRF SearchFilter)
- `ordering=<field>` hoặc `ordering=-<field>`

## 4. Data model (khái niệm)

Dataset N2 được tách thành 6 model chính:

### 4.1 `N2Section`

Nhóm lớn: `Doc`, `Nghe`, `NguPhap`, `TuVung` (code là slug).

Fields chính:
- `code` (slug, unique)
- `name`
- `description`
- `sort_order`

### 4.2 `N2Subcategory`

Nhóm con theo từng section (vd `DoanVanNgan`, `DocHieuTongHop`, `NgheHieuTongHop`, `CauTaoTu`).

Fields chính:
- `section` (FK -> `N2Section`)
- `code` (slug)
- `source_key` (key gốc trong dataset, dạng CamelCase)
- `name`
- `sort_order`
- `metadata` (JSON)

### 4.3 `N2Exam`

Mỗi file JSON nguồn -> 1 exam.

Fields chính:
- `subcategory` (FK -> `N2Subcategory`)
- `slug`, `name`
- `source_file` (đường dẫn tương đối của JSON)
- `source_kind` (lấy từ row đầu tiên nếu có)
- `time_limit_seconds`
- `question_count`
- `is_active`
- `metadata` (JSON)

### 4.4 `N2Question`

1 question tương ứng 1 “row” trong `Questions.Questions[]`.

Fields chính:
- `exam` (FK -> `N2Exam`)
- `source_id` (id trong dataset)
- `display_order`
- `kind`, `title`, `jlpt_level`
- `score`, `scores` (JSON), `correct_answers` (JSON), `time_tracking`
- `general_audio_url`, `general_image_url`
- `general_txt_read`, `general_text_read_en`, `general_text_read_vn`
- `source_import`, `raw_general` (JSON, để trace dữ liệu gốc)

### 4.5 `N2QuestionItem`

Mỗi phần tử trong `content[]` của `N2Question`.

Fields chính:
- `question` (FK -> `N2Question`)
- `item_order`
- `question_text`
- `image_url`
- `answers` (JSON array; giữ nguyên cấu trúc dataset)
- `choose_answer` (int, optional)
- `correct_answer` (int, optional)
- `explain_en`, `explain_vn`
- `raw_explain`, `raw_data` (JSON gốc)

Lưu ý quan trọng:
- `choose_answer` nằm trên **record dataset** nên mang tính **global** (mọi user sẽ “đè” nhau).
  Nếu bạn muốn tracking theo từng user, hãy dùng Practice Attempts API: `docs/api/practice.md`.

### 4.6 `N2MediaAsset`

Registry các file media đã upload lên R2 (dùng để debug và cache mapping).

Fields chính:
- `source_type`: `LOCAL` hoặc `REMOTE`
- `media_type`: `IMAGE` | `AUDIO` | `OTHER`
- `source_url` (nếu là remote fallback)
- `source_path`, `source_basename` (nếu là local)
- `r2_key`, `public_url`, `content_type`, `content_length`
- `metadata` (JSON)

## 5. API endpoints (chi tiết)

Tất cả endpoint dưới đây đều hỗ trợ CRUD:

- List: `GET /api/n2/<resource>/`
- Create: `POST /api/n2/<resource>/`
- Detail: `GET /api/n2/<resource>/{id}/`
- Update: `PUT/PATCH /api/n2/<resource>/{id}/`
- Delete: `DELETE /api/n2/<resource>/{id}/`

### 5.1 Sections: `/api/n2/sections/`

Query params:
- `search` (search fields: `code`, `name`, `description`)
- `ordering` (fields: `sort_order`, `name`, `updated_at`)
- `page`, `page_size`

### 5.2 Subcategories: `/api/n2/subcategories/`

Filter params:
- `section=<id>`
- `section_code=<slug>`

Search fields: `name`, `code`, `source_key`, `section__name`, `section__code`  
Ordering fields: `sort_order`, `name`, `updated_at`

### 5.3 Exams: `/api/n2/exams/`

Filter params:
- `section=<id>`
- `section_code=<slug>`
- `subcategory=<id>`
- `subcategory_code=<slug>`
- `is_active=true|false|1|0|yes|no`

Search fields: `name`, `slug`, `source_file`, `source_kind`, `subcategory__name`  
Ordering fields: `name`, `question_count`, `time_limit_seconds`, `updated_at`

#### Custom: `GET /api/n2/exams/{id}/questions/`

Trả về danh sách `N2Question` thuộc exam đó (có pagination).

### 5.4 Questions: `/api/n2/questions/`

Filter params:
- `section=<id>` / `section_code=<slug>`
- `subcategory=<id>` / `subcategory_code=<slug>`
- `exam=<id>`
- `kind=<text>`
- `source_id=<int>`

#### Custom: `GET /api/n2/questions/{id}/items/`

Trả về danh sách `N2QuestionItem` của question (không pagination).

### 5.5 Question Items: `/api/n2/question-items/`

Filter params:
- `question=<id>`
- `exam=<id>`
- `subcategory=<id>`
- `section=<id>`

### 5.6 Media Assets: `/api/n2/media-assets/`

Filter params:
- `media_type=IMAGE|AUDIO|OTHER`
- `source_type=LOCAL|REMOTE`

## 6. Import JSON + upload media lên R2

### 6.1 Chuẩn bị

- Folder dataset: `n2/` (bao gồm JSON + images/audio).
- R2 public base: `R2_PUBLIC_BASE_URL` (vd `https://storage.jlpt.codes`)
- Bucket: `R2_BUCKET_NAME` (vd `startjlpt`)

### 6.2 Chạy import (local)

Upload local media lên R2 và import vào DB:

```bash
PYTHONUNBUFFERED=1 \\
python manage.py import_n2_data --source-dir n2 --prefix n2/images --clear
```

Nếu muốn **re-import** nhanh (media đã upload rồi):

```bash
PYTHONUNBUFFERED=1 \\
python manage.py import_n2_data --source-dir n2 --prefix n2/images --skip-upload-local
```

Nếu muốn bỏ qua download/upload remote media URLs (nếu JSON còn link media remote chưa có local):

```bash
PYTHONUNBUFFERED=1 \\
python manage.py import_n2_data --source-dir n2 --prefix n2/images --skip-upload-remote
```

## 7. Tracking tiến độ theo user (Option 2)

Để lưu câu trả lời theo từng user và chấm điểm:

- Xem `docs/api/practice.md`
- Flow:
  1. `POST /api/practice/attempts/` (level=`N2`, exam_id)
  2. `GET /api/n2/exams/{exam_id}/questions/`
  3. `POST /api/practice/attempts/{attempt_id}/answers/`
  4. `POST /api/practice/attempts/{attempt_id}/submit/`
